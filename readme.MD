
Revisited version of the Rock Paper Scissors game now has an interactive overlay instead of being a console game. 

The same logic  follows for computer choice, however, you can choose one of the three buttons.
After choosing a button, there's a text stating chosen moves, state of the round, and total score. 
Upon reaching score 6, winner is declared and buttons are disabled until you press "Restart" button. 
Pressing restart button enables buttons again, and newly started game cannot be restarted. 
There is light and dark mode, which is done by toggling class through JS. 
Almost all of the functionalities are done through JavaScript via DOM.

[OLD DESCRIPTION]

This is a Rock Paper Scissors (console) game created according to instructions in 
    https://www.theodinproject.com/lessons/foundations-rock-paper-scissors 

Computer is randomly assigned one of the options and user is prompted to choose one. If chosen none, the user will be prompted until correct input is given. 

During each round, there is a text stating the winner as well as the moves.

After 5 rounds, the winner is stated and the game ends.
